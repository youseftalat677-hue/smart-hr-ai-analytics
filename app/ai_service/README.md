# # Smart HR AI Analytics System 🚀

**FastAPI** و **Groq AI (Llama 3.3)** نظام تحليل بيانات الموارد البشرية الذكي باستخدام

---

## 🌟 الميزات الرئيسية (Features)

1. **AI Performance Insights**:
   - تحليل أدوات الموظفين وتقديم تحليلات واستنتاجات ذكية.
   - دعم نظام التراجع الآمن (**Safe Fallback Behavior**) لضمان استقرار الخدمة عند انقطاع الاتصال.

2. **HR Policy Assistant**:
   - مساعد ذكي للإجابة على استفسارات وسياسات الموارد البشرية واللوائح الداخلية.
   - التعامل الذكي مع حالات نقص البيانات (**Insufficient Data Handling**) وتوجيه الموظف للخطوات المعتمدة.

3. **Interactive Documentation**:
   - توثيق تفاعلي كامل ومباشر باستخدام **Swagger UI**.
